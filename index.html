A field guide, in one page

How Humans Write, Speak & tell Machines what to do

Three layers of human communication technology: the scripts we write in, the spoken tongues and dialects those scripts capture, and the artificial languages we invented so machines could understand us back.

Writing Systems

Scripts — the visual code for sound & meaning

A script is the set of symbols used to write one or more languages. The same spoken language can sometimes be written in more than one script (e.g. Hindi/Marathi in Devanagari, Urdu in Perso-Arabic) — script and language are not the same thing. Tap the glyphs above or the filters below to explore.

Spoken Tongues

Language families & dialects

Around 7,000 living languages are usually grouped into a few dozen large families based on shared ancestry. Within any one language, dialects branch further by region — Marathi alone has half a dozen recognisable regional forms across Maharashtra.

Artificial Languages

Languages made for machines

Computers only truly understand electrical pulses (binary). Every layer above that — assembly, compiled languages, scripting languages, markup, query languages — is a language humans built to make instructing machines easier for us, not for them.
